NativeThreeBridge 0.6.0 – Real Three.js inside native Windows DirectX 12
======================================================================
Official Three.js classes execute inside the bundled QuickJS-NG engine.
The C++ DX12 renderer receives THREE.InstancedMesh world matrices each frame.
No Chromium, HTML, browser, WebView, or separate Node/Deno install is used.
Exactly 10 original Kuningriigid Stone Age houses and 10 Sapling pines.

1. Extract the whole ZIP into a writable directory.
2. Run NativeThree-Launcher.exe for GitHub automatic updates.
   Or start NativeThree-DX12.exe to skip the updater.
3. Left mouse drag: rotate. Mouse wheel: zoom. Space: pause. ESC: close.
4. If you see a black screen or DX12 error, send a screenshot/error text.
5. Create NO-UPDATE.txt beside the launcher to disable auto-updates.

GitHub Actions ran actual official Three.js in embedded QuickJS and
verified 20 world matrices; physical Windows GPU drawing is unverified.
This is not yet drop-in WebGLRenderer/GLTFLoader compatibility.
