NativeThreeBridge v0.5.0 – Windows DirectX 12 test
===================================================
Exactly 10 original Kuningriigid Stone Age houses and 10 pine trees.
The model geometry and textures are embedded in the EXE.
No Chromium, WebView, Electron, Node, Deno or Python at runtime.

1. Extract this ZIP into a writable folder (e.g. C:\Games\NativeThreeBridge)
2. Run NativeThree-Launcher.exe to check and apply GitHub EXE updates.
   Alternatively, double-click NativeThree-DX12.exe to skip update checks.
3. Left mouse drag: camera orbit. Mouse wheel: zoom.
   Space: pause. Escape: close.
4. If an error or black screen appears, note the exact error dialog.
5. Create NO-UPDATE.txt beside launcher to disable automatic updates.
6. Read launcher.log when investigating update failures.

NativeThree-Diagnostics.exe is now an alias for the DX12 app to remain
compatible with the v0.4 launcher updater.
This is still a prototype, not a full JavaScript/Three.js game engine.
